# 사진 보관함 (Photo Archive)

휴대폰 앨범에서 사진을 한 번에 골라 올리면 **촬영 날짜별로 월간 달력에 자동 정리**되고,
노트북에서 날짜를 눌러 사진을 보고, **3×2cm(또는 2×3cm)로 잘라 A4 PDF로 인쇄**할 수 있는 웹앱(PWA)입니다.

- 주소: https://kimminsu31415.github.io/photo-archive/
- 사진 저장 위치: 내 구글 드라이브의 `Photo Archive` 폴더 (앱은 자기가 만든 파일만 볼 수 있음)
- 휴대폰: 크롬 메뉴 → **홈 화면에 추가**로 앱처럼 설치. 설치 후에는 갤러리에서 사진 선택 → **공유 → 사진 보관함**으로도 보낼 수 있음
- 인쇄: 인쇄 목록 → PDF 저장 → **실제 크기(100%)** 로 인쇄

## 처음 한 번: 구글 로그인 클라이언트 ID 만들기

1. https://console.cloud.google.com 에 접속해 위쪽 프로젝트 선택 → **새 프로젝트** → 이름 `photo-archive` → 만들기
2. 왼쪽 메뉴 **API 및 서비스 → 라이브러리**에서 `Google Drive API` 검색 → **사용**
3. 왼쪽 메뉴 **Google 인증 플랫폼(OAuth 동의 화면)** → **시작하기**
   - 앱 이름: `사진 보관함`, 사용자 지원 이메일: 내 지메일
   - 대상: **외부**
   - 연락처 이메일: 내 지메일 → 동의 후 **만들기**
4. **대상(Audience)** → **테스트 사용자 → 사용자 추가** → 내 지메일 추가 → 저장
5. **클라이언트(Clients)** → **클라이언트 만들기**
   - 애플리케이션 유형: **웹 애플리케이션**
   - 승인된 JavaScript 원본: `https://kimminsu31415.github.io`
   - **만들기** → 나오는 **클라이언트 ID**(`…apps.googleusercontent.com`) 복사
6. 이 저장소의 `config.js`에 붙여넣기 (클라이언트 ID는 공개돼도 괜찮은 값)

처음 연결할 때 "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → 사진 보관함(으)로 이동**을 누르면 됩니다.
내가 만든 개인용 앱이라 나오는 안내입니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조 |
| `style.css` | 무지 플래너 스타일 |
| `app.js` | 달력, 촬영일 읽기(EXIF), 드라이브 저장, 크롭 편집, PDF |
| `config.js` | 구글 클라이언트 ID |
| `sw.js` | 오프라인 화면 캐시, 갤러리 공유 받기 |
| `manifest.webmanifest` | 홈 화면 설치 정보 |
| `vendor/jspdf.umd.min.js` | PDF 생성 라이브러리 (jsPDF 2.5.1, MIT) |
