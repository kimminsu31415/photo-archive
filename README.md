# 사진 보관함 (Photo Archive)

휴대폰 앨범에서 사진을 한 번에 골라 올리면 **촬영 날짜별로 월간 달력에 자동 정리**되고,
노트북에서 날짜를 눌러 사진을 보고, **캘린더형(3.4×2.3cm)·리스트형(2.6×2.6cm)으로 잘라 A4 PDF로 인쇄**할 수 있는 웹앱(PWA)입니다.

- 주소: https://kimminsu31415.github.io/photo-archive/
- 사진 저장 위치: 내 구글 드라이브, 촬영 날짜에 맞춰 연도·월 폴더로 정리
  ```
  Photo Archive/
    2026/
      2026-10/  2026-10-03_IMG_1234.jpg …
      2026-11/  2026-11-02_IMG_1301.jpg …
    언제의 사진/   찍은 날짜를 알 수 없는 사진
  ```
  찍은 날짜는 사진 정보(EXIF) → 파일 이름 → 오래된 파일 날짜 순으로 찾고, 모두 없으면 **언제의 사진?** 칸에 모아 둠
  날짜를 누른 뒤 **＋ 이 날에 사진 추가**로 고른 사진은 찍은 날짜와 상관없이 그 날짜에 들어감 (찍은 시각은 유지)
  앱에서 날짜를 고치면 파일도 해당 월 폴더로 옮겨지고 이름 앞 날짜도 바뀜.
  앱은 자기가 만든 파일만 볼 수 있어서, 드라이브에서 직접 넣은 사진은 앱에 나타나지 않음
- 휴대폰: 크롬 메뉴 → **홈 화면에 추가**로 앱처럼 설치. 설치 후에는 갤러리 앱에서 사진 선택 → **공유 → 사진 보관함** → 찍은 날짜대로 / 정한 날짜에 넣기
  앱의 사진 추가 화면에 구글 포토가 뜨면 설정에서 **갤러리·파일 앱 화면으로 열기**를 켬
- 사진 인쇄: 인쇄 목록 → 캘린더형(34×23mm)·리스트형(26×26mm) 중 선택 → 사진별 ‘편집’으로 인쇄 영역(위치·확대·회전) 맞추기 → PDF 저장 → **실제 크기(100%)** 로 인쇄. 스티커 용지에 맞춰 가장자리 1cm는 항상 비움
- 수첩: 달력 사진을 골라 잡지처럼 꾸미는 한 권의 책 (위쪽 **수첩** 탭)
  - 페이지 레이아웃: 표지 · 에디터 노트 · 무드보드 · 사진 네 장 · 사진 두 장 · 넘버 리스트 · 사진 한 장 · 글
  - 글자는 눌러서 바로 수정, 사진 칸은 눌러서 사진함 사진을 넣고 끌어서 위치·확대 조정, 바탕색 6가지
  - **달력에서 사진 고르기**: 같은 사진(파일이 같거나 원래 찍은 시각·모양이 같은 사진)은 한 번만 담김
  - 사진은 드라이브 파일 ID로 연결돼서 달력에서 날짜를 옮겨도 수첩은 그대로. 달력에서 삭제하면 수첩 칸에 ‘삭제된 사진’으로 표시
  - **넘겨 보기**: 노트북은 펼침면으로 책장 넘기기, 휴대폰은 한 쪽씩 밀어 넘기기
  - **PDF 저장**: A5(148×210mm) 한 쪽 = 한 장
  - 저장 위치: `Photo Archive/수첩/제목.json`
- 메모지 인쇄: A4에 76×76mm 메모지 6칸. 칸마다 투두·줄글·모눈·점선·주간·빈 메모 템플릿 또는 '사용 안 함'
  - 템플릿 칸: 테두리 없이 메모지 안 내용만 인쇄
  - 사용 안 함 칸: 메모지 붙일 자리 가이드(테두리·접착 부분·십자선·눈금) 인쇄
  1. 가이드를 인쇄해 메모지를 붙임 (접착 부분이 종이 위쪽)
  2. 그 종이를 같은 방향으로 넣고 템플릿을 고른 PDF를 실제 크기로 인쇄
  3. 어긋나면 가이드 눈금으로 재서 위치 보정(mm)에 입력

## 처음 한 번: 구글 로그인 클라이언트 ID 만들기

1. https://console.cloud.google.com 에 접속해 위쪽 프로젝트 선택 → **새 프로젝트** → 이름 `photo-archive` → 만들기
2. 왼쪽 메뉴 **API 및 서비스 → 라이브러리**에서 `Google Drive API` 검색 → **사용**
3. 왼쪽 메뉴 **Google 인증 플랫폼(OAuth 동의 화면)** → **시작하기**
   - 앱 이름: `사진 보관함`, 사용자 지원 이메일: 내 지메일
   - 대상: **외부**
   - 연락처 이메일: 내 지메일 → 동의 후 **만들기**
4. **대상(Audience)** → **테스트 사용자 → 사용자 추가** → 내 지메일 추가 → 저장
5. **클라이언트(Clients)** → **클라이언트 만들기**
   - 애플리케이션 유형: **웹 애플리케이션**
   - 승인된 JavaScript 원본: `https://kimminsu31415.github.io`
   - **만들기** → 나오는 **클라이언트 ID**(`…apps.googleusercontent.com`) 복사
6. 이 저장소의 `config.js`에 붙여넣기 (클라이언트 ID는 공개돼도 괜찮은 값)

처음 연결할 때 "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → 사진 보관함(으)로 이동**을 누르면 됩니다.
내가 만든 개인용 앱이라 나오는 안내입니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조 |
| `style.css` | 무지 플래너 스타일 |
| `app.js` | 달력, 촬영일 읽기(EXIF), 드라이브 저장, 크롭 편집, PDF |
| `config.js` | 구글 클라이언트 ID |
| `sw.js` | 오프라인 화면 캐시, 갤러리 공유 받기 |
| `manifest.webmanifest` | 홈 화면 설치 정보 |
| `vendor/jspdf.umd.min.js` | PDF 생성 라이브러리 (jsPDF 2.5.1, MIT) |
